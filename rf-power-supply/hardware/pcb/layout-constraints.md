# PCB 布局约束清单

## 叠层建议（PA 板，4 层）

1. TOP — RF / 功率走线
2. GND — 完整地平面
3. PWR — 总线与局部电源
4. BOT — 回流与屏蔽、少量信号

CTRL 板可用 4 层；PSU 强电按安规与爬电单独评估（可能需 2 oz 铜）。

## 关键规则

| 区域 | 规则 |
|------|------|
| 50 Ω RF | 微带线宽按叠层计算；连续参考地；过孔墙两侧 |
| GaN 半桥 | 驱动环 < 10 mm；去耦 < 2 mm；对称半桥 |
| 检波 | 耦出口同轴或紧耦合微带；远离开关节点 |
| ADC | 模拟地星形；参考与数字地单点；RC 靠近引脚 |
| 隔离 | 驱动器原副边满足爬电；开槽可选 |
| 真空电容区 | 大铜皮散热；高压净空按峰值电压×2 |

## EMC

- 输入共模电感 + Y 电容；机壳搭接 < 5 mΩ
- 风扇电源加磁珠
- RF 仓与数字仓导电衬垫密封
- 电缆：RF 用半柔/低损耗同轴；通信用双绞屏蔽
