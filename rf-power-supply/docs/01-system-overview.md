# 01 — 系统总览

## 1. 应用场景

RF-1K 面向需要稳定 13.56 MHz 射频功率的工艺设备：

- 电容耦合等离子体（CCP）刻蚀 / 清洗
- 磁控溅射 RF 偏压或辅助源
- ICP 线圈激励（经匹配网络）
- 实验室 / 产线通用 50 Ω 射频源

## 3. 控制闭环

系统同时运行三层闭环（优先级由高到低）：

1. **硬保护链（μs 级）**  
   比较器检测过流 / 过压 / 高反射 → 硬件关断门极驱动 → MCU 中断锁存故障。

2. **功率环（1–10 kHz）**  
   定向耦合器检测正向功率 \(P_f\)、反射功率 \(P_r\)，PID/前馈调节 DDS 幅度或 PA 总线电压，使 \(P_f\) 跟踪设定值。

3. **自动匹配环（1–50 Hz）**  
   最小化 \(|\Gamma|\) 或 \(P_r/P_f\)：交替微调串联电容 \(C_s\) 与并联电容 \(C_p\)（梯度下降 / 坐标搜索）。

## 4. 工作状态机

```
IDLE ──set_power>0──▶ RAMP ──ok──▶ RUN
 ▲                      │            │
 │                   fault         fault / stop
 │                      ▼            ▼
 └──────────────────── FAULT ◀───────┘
                          │
                       clear
                          ▼
                        IDLE
```

- **RAMP**：软启动，功率按斜率（默认 200 W/s）爬升，同时启用匹配。
- **RUN**：功率稳定；反射超阈则降功率或进入 FAULT。
- **FAULT**：锁存原因码，关闭 RF，等待人工/上位机清除。

## 5. 机械与热

| 项目 | 建议 |
|------|------|
| 机箱 | 3U 19"，深度 ≤ 500 mm |
| PA 热阻 | GaN + 冷板，目标结温 < 110 °C @ 25 °C 环境 |
| 风道 | 前进后出；匹配舱与 PA 舱隔开，避免电容过热 |
| 屏蔽 | PA/OSC 金属仓；数字板与 RF 仓分腔 |

## 6. 关键安全联锁

- 前面板急停（硬断 DC 总线接触器）
- 机盖互锁
- 负载连接检测（可选）
- 水冷流量开关（水冷选配）
- 外部 ENABLE 干接点（工艺主机联锁）
