# 02 — 硬件设计

## 1. PSU 板 — 隔离 DC 总线

### 拓扑

1. **前端 EMI + 整流**：差模/共模滤波 → 桥堆 → 电解母线。
2. **PFC**：CRM 或 CCM 升压 PFC，输出约 390 VDC，满足 IEC 61000-3-2。
3. **隔离级**：全桥 LLC（推荐）或移相全桥，次级同步整流得到 **48–60 V** 可调总线。
4. **辅助电源**：Flyback 提供 +15 V（门驱）、+5 V、+3.3 V。

### 关键参数

| 参数 | 值 |
|------|-----|
| 额定输出 | 55 V / 25 A（约 1.4 kW，留裕量） |
| 纹波 | < 200 mVpp @ 满载 |
| 效率目标 | ≥ 92% |
| 过流 | 硬件限流 + 软件 OCP |

功率环可选两种执行器：

- **A. 调幅（AM）**：固定总线，DDS 幅度控制（实现简单，效率在轻载略差）。
- **B. 调压（推荐）**：DDS 满幅，调节 LLC 参考电压 → PA 总线；轻载效率更好。

本参考设计默认 **B + 小范围 AM 微调**。

## 2. OSC 板 — 激励与驱动

### DDS

- 芯片：AD9834 / AD9951，或 MCU 片内 HRTIM + 外部滤波（成本方案）。
- 推荐：**AD9951** 或 Si5351（低成本）+ 外部幅度控制（DAC → VGA 或乘法器）。
- 频率：13.560000 MHz，温补晶振 TCXO 10/25 MHz。

### 门极驱动链

```
DDS/方波 → 死区逻辑（20–40 ns 可调） → 隔离驱动（Si823x / ADuM4121）
         → GaN 专用驱动器（如 LMG1210） → GaN HEMT 半桥
```

要点：

- 死区过小 → 直通；过大 → 效率下降、EMI 变差。量产标定。
- 隔离电源：每桥臂独立 +6 V / −3 V（按所选 GaN 推荐）。
- 所有驱动回路最小化，Kelvin 源感。

## 3. PA 板 — 功率放大与滤波

### 半桥 Class-D / Class-EF

| 器件 | 示例 | 说明 |
|------|------|------|
| 开关管 | GS61008T / EPC2034 并联 | 100 V 级 GaN，低 Coss |
| 输出网络 | Class-EF / 低通 L 型 | 滤除开关谐波，匹配 50 Ω |
| 定向耦合器 | 双定向 30–40 dB 耦合 | Pf / Pr 采样至 RMS 检波 |
| 检波 | AD8307 / LTC5507 | log 检波，宽动态范围 |

输出低通示例（13.56 MHz，50 Ω）：

- \(L_1 \approx 500\,\mathrm{nH}\)（空心或低损耗磁芯）
- \(C_1 \approx 270\,\mathrm{pF}\)（NPO / 云母，高压）

精确值需用 Smith 图 / ADS 按实际寄生优化。

### 定向耦合器与功率换算

\[
P[\mathrm{W}] = 10^{(V_{\mathrm{det}}-V_0)/k}/1000
\]

固件内用查找表或分段拟合校准 \(V_0, k\)。建议出厂两点校准：10 W、1000 W。

## 4. MATCH 板 — 自动匹配网络

### L 型网络

等离子体负载多为低电阻 + 容性电抗，**优先采用 series-L + shunt-C**（或气可变电容 + 抽头电感）。双真空电容（Cs/Cp）适合较窄的 Smith 圆图覆盖区。

```
# 推荐（低 R 负载）          # 备选（双电容）
RF_in ── L ──┬── Load        RF_in ── Cs ──┬── Load
             C                            Cp
            GND                           GND
```

- 可变元件：真空可变电容 5–1000 pF，耐压 ≥ 5 kV；电感可用抽头或可调磁芯。
- 驱动：两路步进电机 + 减速箱；光电限位 + 多圈电位器/编码器位置反馈。
- 可选：气动快速短路棒用于大阻抗跳变工艺。
- 拓扑选择可用 `sim/match_solver.py` 对目标 ZL 扫描。

匹配算法见固件文档；硬件需保证：

- 电机驱动与 RF 地良好隔离或单点接地。
- 真空电容外壳可靠接地，避免机壳发热。

## 5. CTRL 板 — 控制与保护

### MCU

**STM32H743VIT6**（或同级）：

| 资源 | 用途 |
|------|------|
| ADC1/2/3 | Pf, Pr, Vdc, Idc, Temp×N, 位置 |
| DAC / SPI-DAC | 幅度 / 总线电压给定 |
| HRTIM / TIM | 死区调试、风扇 PWM |
| UART + RS485 | Modbus-RTU |
| ETH | LwIP TCP 控制 |
| GPIO | 接触器、使能、故障灯、急停输入 |

### 硬件保护（优先于软件）

| 通道 | 检测 | 动作 |
|------|------|------|
| 过流 | 分流器 + 比较器 | 关断驱动使能 |
| 过压 | 总线分压比较 | 关断 / 晶闸管泄放 |
| 高反射 | Pr 比较器 | RF OFF |
| 过温 | NTC / 热敏 | 降额或关断 |
| 弧光 | 电流尖峰 / 光传感 | 微秒级 blanking |

所有保护输出经 **锁存**，需 CTRL 发 CLEAR 才释放。

## 6. PCB 与布局要点

1. **分区**：强电 PSU | RF PA | 数字 CTRL，分地后单点汇合。
2. **RF 走线**：50 Ω 微带/带状线，参考完整地平面；过孔栅栏屏蔽。
3. **GaN**：环路面积最小化；驱动电阻就近；去耦 100 nF + 1 µF 紧贴漏极。
4. **磁件**：输出电感远离 MCU 与 ADC 参考。
5. **爬电**：AC 侧按 220 V 加强绝缘；RF 高压电容区 ≥ 8 mm 空气间隙（视峰值电压调整）。
